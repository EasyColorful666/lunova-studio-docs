本网站使用 shadcn-docs-nuxt 构建，这是一款现代化的静态网站生成器

### 安装

```sh
pnpm install
```

### 本地开发

```sh
pnpm run dev
```

此命令会启动一个本地开发服务器，并打开一个浏览器窗口。大多数更改会实时反映出来，无需重启服务器

### 生成

```sh
pnpm run generate
```

此命令会将静态内容生成到 `.output` 目录中，并且可以使用任何静态内容托管服务进行部署
